For this assignment, I created a Python program that connects to a Supabase database to manage customer orders. I started by setting up my database and importing customer, product, and order data into Supabase.

I then connected Python to Supabase using my database configuration files. My program retrieves and displays customer and product information, allowing the user to select a customer, choose a product, and enter a quantity.

I added input validation to make sure the user enters valid IDs and a positive quantity. The program calculates the total price, displays an order summary, and asks the user to confirm or cancel the purchase.

Once an order is confirmed, the program saves it to Supabase and retrieves it again using the generated order ID to verify that it was successfully recorded.

This assignment helped me practice Python functions, loops, conditionals, error handling, and working with a database through an API. I was able to get my program running and connecting to Supabase successfully.
